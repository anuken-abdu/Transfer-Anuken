# Anuken Transfer

Сервис трансферов и аренды авто с водителем. Три приложения на одной базе: сайт для клиентов, диспетчерская и приложение водителя. Заказ с сайта сразу появляется у диспетчера, назначенный водитель получает его на телефон, клиент видит статус и машину по своей ссылке.

```
anuken-transfer/
├── supabase/
│   ├── migrations/0001_init.sql      схема, защита доступа, вся логика заказов
│   ├── seed.sql                      города, классы авто, стартовые тарифы
│   ├── functions/admin-create-user/  создание аккаунтов водителей из админки
│   └── tests/                        локальные тесты базы (52 сценария)
├── client/                           сайт для клиентов: бронирование и отслеживание (RU/EN)
├── admin/                            диспетчерская
└── driver/                           приложение водителя: устанавливается на телефон
```

## Что уже умеет

Заказы: создание диспетчером, приём заказов с сайта и из приложения клиента (функция `create_order`), фиксированные маршруты, почасовая аренда, межгород, цена по запросу для своих маршрутов, скидки компаниям, назначение водителя с проверкой класса и мест, статусы от «Новый» до «Выполнен», журнал изменений, отмена с причиной, ссылка для клиента на отслеживание машины.

Водители: аккаунт с логином и паролем, машины, комиссия сервиса на каждого водителя, «на линии / на заказе / не на линии», геопозиция. Водитель видит только свои заказы и не может менять цены или комиссию.

Цена всегда считается на сервере, клиент не может её подделать. Заказы с сайта без входа ограничены: минимум за 30 минут, не больше 5 активных на один номер.

Приложение водителя: выход на линию, лента заказов с сигналом о новом, карточка заказа с навигацией в 2GIS, Яндекс и Google, звонок и WhatsApp клиенту, табличка для встречи на весь экран, проверка рейса, большая кнопка статуса («Выехал → На месте → Клиент в машине → Завершить»), отказ с причиной, сумма к получению наличными, заработок за день, неделю и месяц. Пока заказ идёт, экран не гаснет, а геопозиция уходит диспетчеру и клиенту.

Сайт для клиентов: заказ без регистрации — город, трансфер по маршруту, почасовая аренда или межгород, класс авто с ценой сразу, дата и время, адреса, встреча в аэропорту с номером рейса и табличкой, детское кресло, пожелания, оплата наличными или Kaspi водителю. После заказа клиент получает личную ссылку: статус по шагам, имя водителя, машина и номер, звонок водителю, «Где машина» в 2GIS, отмена онлайн (до выезда водителя и не позже чем за час). Ссылки сохраняются в «Моих заказах» на телефоне. Русский и английский.

Диспетчер слышит сигнал и видит всплывающее уведомление о каждом новом заказе с сайта, на любой странице админки.

Админка работает на телефоне и компьютере, тёмная и светлая тема по настройке устройства, обновляется сама при новых заказах.

## Запуск

### 1. Supabase (сервер, база и вход) — 10 минут

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project**, регион **Central EU (Frankfurt)** — ближайший к Казахстану. Тариф Free для старта хватает.
2. **Authentication → Users → Add user → Create new user**: ваш email и пароль, галочка **Auto Confirm User**.
3. Откройте `supabase/setup.sql`, в самой последней строке замените `ВАШ_EMAIL` на этот email.
4. **SQL Editor → New query** → вставьте весь `setup.sql` → **Run**. Это создаёт базу, тарифы и делает вас администратором.
5. **Edge Functions → Deploy a new function → Via Editor**, имя `admin-create-user`, вставьте код из `supabase/functions/admin-create-user/index.ts` → **Deploy**. Без неё админка не сможет добавлять водителей.
6. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public** — они нужны для Vercel.

Файлы `migrations/` и `seed.sql` — то же самое по частям, для разработки; при запуске через `setup.sql` их выполнять не нужно.

### 2. Код на GitHub

Создайте приватный репозиторий и загрузите в него папку `anuken-transfer` целиком.

### 3. Админка на Vercel

1. Залейте папку проекта в GitHub.
2. Vercel → **Add New Project** → репозиторий → **Root Directory: `admin`** (Vite определится сам).
3. **Environment Variables**:
   - `VITE_SUPABASE_URL` — Project URL
   - `VITE_SUPABASE_ANON_KEY` — anon public ключ
   - `VITE_SITE_URL` — адрес будущего сайта, например `https://anuken-transfer.kz` (для ссылок отслеживания)
4. Домен: Vercel → Settings → Domains → `admin.anuken-transfer.kz`, у регистратора CNAME `admin` → `cname.vercel-dns.com`.

### 4. Приложение водителя на Vercel

Так же, как админка: новый проект Vercel из того же репозитория, **Root Directory: `driver`**, те же `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Домен — `driver.anuken-transfer.kz` (CNAME `driver` → `cname.vercel-dns.com`).

### 5. Сайт для клиентов на Vercel

Третий проект Vercel из того же репозитория, **Root Directory: `client`**, переменные:
- `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` — те же;
- `VITE_DISPATCH_PHONE` — номер диспетчера для кнопок «Позвонить» и WhatsApp, например `+77070000000`.

Домен — основной `anuken-transfer.kz` (A-запись `@` → `76.76.21.21` и CNAME `www` → `cname.vercel-dns.com`). Ссылки отслеживания имеют вид `anuken-transfer.kz/t/…`; в админке `VITE_SITE_URL` должен совпадать с этим доменом.

### 6. Подключить водителей

1. В админке: «Водители» → «Добавить» → ФИО, телефон, email, пароль. Затем в карточке водителя добавьте его машину.
2. Отправьте водителю ссылку `https://driver.anuken-transfer.kz`, email и пароль.
3. Водитель открывает ссылку и устанавливает приложение:
   - Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран»;
   - iPhone (Safari): кнопка «Поделиться» → «На экран Домой».
4. В приложении: «Профиль» → «Уведомления» → «Включить».

Что важно знать водителям: геопозиция и сигнал о новом заказе работают, пока приложение открыто или свёрнуто недавно. Во время заказа держите приложение на экране — экран не будет гаснуть.

### Посмотреть без Supabase

```bash
cd admin && npm install && npm run demo    # диспетчерская
cd driver && npm install && npm run demo   # приложение водителя
cd client && npm install && npm run demo   # сайт для клиентов
```
Обе части откроются на тестовых данных в памяти браузера. В демо водителя через 25 секунд «приходит» новый заказ.

### Тесты базы

Нужен локальный PostgreSQL 15+:
```bash
supabase/tests/run.sh
```

## Цены

Тарифы в `seed.sql` ориентировочные. Меняйте в админке: раздел «Тарифы», переключатель города вверху. Классы: Комфорт, Бизнес, Минивэн, VIP.
